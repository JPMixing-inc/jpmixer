# Shure wireless

Each Shure wireless mic's name, battery and transmitter on FOH Home's Wireless card, the musician's phone mixer, Monitor Engineer and the Green Room, the way Wireless Workbench shows them. An official JPMixer plugin.

- QLX-D, ULX-D, SLX-D and Axient Digital receivers, read through Shure's control port (TCP 2202) with GET strings only. It never changes a receiver or turns on its meters.
- Receivers are found by listening for their announcements (while Wireless Workbench or another controller is open), or added by address.
- Set it up in JPMixer under Settings → Plugins → Shure wireless: tick the receivers to read, and give each mic the mix it belongs to.
