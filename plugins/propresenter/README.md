# ProPresenter

ProPresenter on JPMixer's Home pages (FOH, ProPresenter, Lighting, Switcher, Producer and any Home pages added for other roles), through ProPresenter's own network API, the one ProPresenter Control uses. An official JPMixer plugin. Needs JPMixer 2.0.19 or later and ProPresenter 7.9 or later.

- **ProPresenter, a controller:** pictures of the current and next slide with their words (or the media on screen), Previous, Next, Clear slide, Clear media and Clear All, up to four timers, and the stage message.
- **Timers:** every timer's time, live, with Start, Stop and Reset.
- **Audience messages:** show and hide ProPresenter's messages (once it has some).
- **Running timers at the top:** while a timer runs, it's under the header of every Home page and next to the clock on the Green Room screen (a setting turns it off).
- **Macros & Looks:** a button for each macro, and for each Look, with the live Look marked.
- Anyone with a Home page open can use the buttons. On FOH Home, an FOH code covers them too.
- Set it up under Settings → Plugins → ProPresenter: the ProPresenter computer's address and the port from ProPresenter → Settings → Network (with Enable Network on).
