On the console: Utility → Control → MIDI has its own On/Off/Secure Mode switch for MIDI/TCP — it must be turned on there before JPMixer (or anything else) can connect, the same way DiGiCo consoles need DiGiCo Pad enabled. Unlike DiGiCo Pad, though, dLive doesn't limit this to one connection at a time — JPMixer can run alongside Director, MixPad, and other control apps without conflict.
Base MIDI Channel must match the value set on the console under Utility → Control → MIDI (0-11, i.e. MIDI channel 1-12).

External Control API

Lets external tools — Bitfocus Companion, Elgato Stream Deck (via Companion or a plain HTTP action), or anything else that can make an HTTP request — mute channels, fire snapshots, and rename channel/aux labels. Anyone with the token below can do all of that, so treat it like a password. (Planning Center has its own tab — it doesn't need this API enabled.)
Runs independently of the console connection — enabling or disabling this never restarts or interrupts it.
Auth: send the token as Authorization: Bearer <token>, or as a ?token= query parameter if your tool can't set headers.
Endpoints (all under http://<this Mac's IP>:<port>/api/v1/):
GET /status · GET /channels · GET /auxes
POST /channels/:n/label {label}
POST /auxes/:n/label {label}
POST /auxes/:n/mute {channel, muted} · POST /auxes/:n/solo {channel, soloed}
POST /scenes/fire {action: "next"|"prev"}
